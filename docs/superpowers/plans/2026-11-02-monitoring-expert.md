# 油藏监测与措施专家研判实施计划

> 执行方式：本会话直接执行，沿用现有GitHub Pages静态架构。

目标：新增井层连通图、压裂酸化评价、老区EOR评价；所有计算解释来源、模型、区间和边界，研判以待审核记录进入决策平台收件箱。

## 约束
- 实测与人工演示严格区分；Volve不与虚构监测井关联。
- 示踪剂首次见剂是采样时间括区，不冒称95%置信区间；微地震包络不等于有效导流或支撑体积。
- 生产差额为前趋势基线关联估计，无对照不宣称因果收益；未审核案例不形成成功概率。
- 95%均值置信区间和单次预测区间分开；分类概率不等于置信度。
- 决策收件箱使用同源浏览器存储，明确本地传递、无跨用户/服务器送达能力。
