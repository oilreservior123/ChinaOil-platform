# 基于油藏孪生体的油藏开发措施设计与效果评价平台

用户已在2026-11-02以“继续”批准上一轮六模块设计及GitHub部署。目标是为科研方案比选提供可复算的网页工作台，沿用agent红白金界面，新增dist/twin独立入口，部署到原仓库GitHub Pages。保留其他平台。

依据PPT48—52页：油藏/井筒/管网状态、现场可调变量、增油/控水/能耗目标、MOPSO/NSGA-II/GA、约束校验及风险分级。措施设计扩展到压裂/酸化的等效产能指数变化、调剖堵水的等效相渗变化及配注，不冒充现场精细设计。

方案：浏览器实际执行降阶油水储罐机理模型、三类统计预测器、案例相似度和三类优化算法；全物理耦合仿真另提供OPM文档及现有模拟入口，不伪装已接通。沿用decision大模型网关，未配置时显示本地依据模板。GitHub Pages不存放密钥。

页面：总览与孪生、方案设计、五曲线预测、参数优化、效果评价、模型与数据、专家报告。全部图表有动态解读。油水比=标准体积油/水，水为零显示不可定义。概率为模拟分位数，不冒充现场成功概率。经济项为可编辑研究假设。

数据：复用公开Volve抽样及已有合成井组；井筒压力不当作实测油藏平均压力。无确认措施标签的Volve不虚构措施因果。上传保留于浏览器内存；按井和时间切分，默认70/15/15，显式独立分区优先，严格日期隔离。机理/寻优/类比检索不伪造训练比例。

验收：五类观测/预测曲线、分区指标/残差/耗时、公式/结构/参数注释、三种可执行优化算法、可行解前沿、数值步长复核、结果CSV与报告下载。测试涵盖缺失/零值/硬约束/时间泄漏/无解/复现性；浏览器验证交互和移动布局。发布只上传新增源码与生成样例，不上传PPT。
