# ChinaOil GeoTwin 2.0 · 模型训练与计算工作台

新增13类模型统一数据接口：训练、验证、测试、整体数据、推理输入；CSV/JSON/JSONL校验、特征字典、分区模板、结构图、实际耗时和JSON/CSV结果下载。红白金配色参考中国石油红黄标识，属独立科研演示设计。

## 新版启动

```bash
pip install -r backend/requirements.txt
python -m uvicorn backend.dev:app --host 127.0.0.1 --port 8000
```

打开 http://127.0.0.1:8000/#studio ，训练服务地址填写 http://127.0.0.1:8000 ，检查连接后选择模型并载入演示数据即可计算。仅运行静态页面时不能训练Python模型；GitHub Pages需另接HTTPS计算服务。详细见 backend/README.md 与 docs/GITHUB_DEPLOYMENT.md。

每次请求使用本次train重新拟合，validation选参数，test独立评价，input用于新数据计算；下载结果包括JSON权重或参数。深度模型为从头训练的精简结构，无官方预训练能力承诺。机理/规则模型不伪装训练时长。

数据包：dist/downloads/model-data/model_data_kit.zip；每模型五类JSONL，另附CSV、字段字典、来源、实际比例及SHA256。原ZIP76个完整文件的逐项用途见同目录 original_zip_model_mapping.csv / .md。

源码/服务分发包包含运行所需静态数据与新版全部样例，不重复放入3个大型历史下载归档（public_training_data.zip/model_experiments.zip/physics_experiments.zip）；这些仍可从已有平台下载后放回dist/downloads/。GitHub仓库将两个大型归档分片保存在artifact-parts/；完整检出后运行 `python3 scripts/assemble-downloads.py` 校验并重组。GitHub Actions发布时自动执行，平台仍下载完整ZIP。

# ChinaOil GeoTwin · 智慧油藏协同研究平台

依据用户提供的《智慧油藏开发决策关键技术研究与集成应用》PPT第1–25页制作。完整功能目录可按页检索；指定模型链路实现交互和科学演示，其余仅保留入口。

## 使用

网页为无构建依赖的HTML/CSS/JavaScript应用。通过HTTP服务打开`dist/index.html`，不要用file协议直接打开：

```bash
python -m http.server 8080 --directory dist
```

访问`http://localhost:8080`。算法与状态约束检查：

```bash
npm test
npm run check
```

## 页面

1. 决策总览：科研工作台、可旋转的油藏关联示意、实际数据规模与开发趋势。

3. 知识抽取与图谱：属性图查询/可视化、UIE实际预测与标注对照、实体规范对齐、RotatE候选关系、日历时滞关联、业务检索。
4. 单井与井组：一井一码、日/月数据、井层/井组/区块演示映射、真实油田汇总CRM与独立受控CRM试验、时滞查询。
5. 动态诊断：单井/生成井组/生成区块选择、候选事件与历史模式、受控异常模型测试、地面注采比筛查、事件前观测的Arps探索拟合。
6. 裂缝与模拟：公开DFN几何及统计生成方案；浏览器中重新求解EDFM油水两相压力/输运，查看压力、饱和度、产量、守恒和数值残差。
7. 智能工作流：8节点DAG，质控→知识/诊断→机理→裂缝装配→EDFM→产能评价→依据链，支持演示故障阻断与移除故障后重试。
8. 模型实验室：模型名称/结构/运行方式、真实训练/验证/测试数量及比例、样例、指标、原始脚本和检查点下载。

## 实际运行与模型边界

| 模型/方法 | 运行方式 | 本次评价范围 |
|---|---|---|
| Isolation Forest | 已训练森林导出，浏览器实际推理 | 人工注入尖峰，不代表自然异常准确率 |
| RotatE | 实际复数旋转训练，浏览器实际评分 | 591条公开图关系，filtered head/tail排名 |
| GRIN精简结构复现 | 实际双向图消息GRU训练，冻结测试推理 | 641个遮蔽观测；自然缺失无真值，负预测待核查 |
| UIE式精简结构复现 | 提示条件Transformer跨度模型，冻结推理 | 中文模板事实语料，测试Exact-span F1约0.332；非官方预训练权重，需人工复核 |
| Anomaly Transformer精简结构复现 | 实际关联注意力/高斯先验训练，冻结推理 | 物理有界受控扰动；6口井18个导出窗口；无匹配窗口时显示不可用 |
| Arps | 浏览器实际拟合与留出评价 | 生成解析基准或可选实际观测；适用条件需确认 |
| CRM | 受控机制参数恢复＋真实汇总数据基线 | 二者分开；真实Volve基线外推R²约−0.673，非可靠现场预测 |
| EDFM | 浏览器PCG压力＋保守隐式油水输运 | 120基质＋276裂缝未知量；无气、重力、毛管力或全地质力学 |
| DFN | 公开几何导入＋明确生成的应力权重方案 | 无现场裂缝真值，不报告预测准确率 |
| 实体对齐/业务检索 | 本体词典、编码规则、字符与图谱检索基线 | 不是BGE预训练模型；结果保留数据来源 |

冻结测试推理会明确显示窗口/井/变量和输入、原预测、评估目标；页面不会伪装为在线重新训练。模型训练脚本、权重、真实指标与复算验证在`dist/assets/models`及`dist/downloads/model_experiments.zip`。

## 数据来源

当前附加ZIP尾部不完整。76个完整文件按ZIP局部头逐项解压并验证CRC与长度后恢复，主要生产、测井、图谱及模拟数据完整可读。未将残缺预览图或缺失模型文件当数据使用。

- FORCE：28井、81,220条抽样测井，按20/4/4口井隔离。
- 298篇中文抽取语料由真实表格事实生成，非原始报告。
- OPM SPE1/SPE9公开算例和PorePy裂缝几何。
- 井组、小层及“演示区块”映射明确生成；不代表真实开发归属或物理连通。
- EDFM开度、黏度、孔隙度和边界压力为演示假设；输出不等同现场产能预测。

原来源URL、校验记录和适用许可附在`dist/downloads`；不同来源的原许可独立保留。模型权重仅供本次科研演示，不将数据或模型统一冒称MIT/CC许可。
